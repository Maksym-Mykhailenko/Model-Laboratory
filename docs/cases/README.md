# Scientific cases

Scientific cases are complete, inspectable uses of Model Laboratory rather than isolated feature
examples. Each case connects a scientific question to a model source, declared analysis, numerical
results, figure, and reproducible `.mlab` experiment.

| Case | Scientific question | Included material |
|---|---|---|
| [Dispersion in a six-level Gaussian hierarchy](gaussian-hierarchy-dispersion.md) | Can two relaxation spectra share their endpoints, condition number, and geometric mean while retaining different internal structure and recovery dynamics? | YAML model, 27-step analysis recipe, reference results, figure, checksums, and `.mlab` bundle |

Case materials inherit the repository licence unless a file states otherwise. A case documents
what a particular model establishes; it does not expand the declared scope of the underlying
scientific capability packs.
